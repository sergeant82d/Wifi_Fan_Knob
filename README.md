\# WiFi Fan Knob



ESP32-S3 PWM fan controller with rotary display, WiFi config, OTA updates, and Home Assistant integration.

\## Quick Start

1\. Clone repo

2\. Open in VS Code with PlatformIO

3\. Connect ESP32-S3 board

4\. Run `platformio run --target upload`
